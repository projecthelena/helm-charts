Project Helena Charts

Uptime monitoring, adaptive latency alerts, and status pages.

What's this?

This static index lives at charts.projecthelena.com and serves the Helm repository. Use it to install Warden uptime monitoring on Kubernetes. Get the source on GitHub.

Quick Start

helm repo add projecthelena https://charts.projecthelena.com
helm repo update

# Install warden
helm install warden projecthelena/warden \
  --namespace warden --create-namespace
